No green claim without the receipts.

If a company wants to profit by calling something green, sustainable, carbon neutral, or zero emission, it should have to prove the claim across the product's full supply chain.

Count everythingMaterials, production, shipping, use, and disposal
Name the comparisonBetter than what, where, and for how long?
Publish the receiptAssumptions, uncertainty, offsets, and verifier
Open the full project The claim stays voluntary. The proof does not.
“Zero tailpipe emissions” is not the same as “zero impact.”
