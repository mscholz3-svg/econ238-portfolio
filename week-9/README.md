# Week 9: Acknowledged. Not Transferred.

This folder contains the public-facing creative piece for Week 9 of ECON 238.

## Public page

Open `index.html` through GitHub Pages.

## Format

The project is a clearly labeled satirical mock social-media feed. The fictional posts use humor to examine institutional signaling, property rights, environmental justice, and tribal management of national parks.

## Main question

If a land acknowledgment changes no rights, incentives, or resources, what exactly has changed?

The page connects environmental justice, property rights, tribal economic development, symbolic land acknowledgments, and a proposal for tribal management of national parks.
